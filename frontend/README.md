# 🚗 RideSharingPlatform

A modern Android ride-sharing app built using Kotlin and XML.

---

## ✨ Features

### 🗺️ Map Integration
- Google Maps integrated
- Select pickup and drop locations
- Latitude, longitude, and address captured

### 🔍 Search Rides
- Search available rides
- Loading animation while fetching results
- Clean UI with ride cards

### 🚕 Book Ride
- Booking animation on click
- Simulated ride request flow

### 📤 Offer Ride
- Publish a ride with:
  - Pickup & drop
  - Date & time
  - Seats
  - Price
  - Vehicle type
  - Notes

### 📄 Ride Summary
- Shows complete ride details after publishing
- Status: Pending

### 📋 My Requests
- View:
  - Offered rides
  - Booked rides
- Status indicators:
  - Pending
  - Accepted
  - Completed
